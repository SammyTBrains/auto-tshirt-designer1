STEP 1: Get Your API Token
---------------------------
1. Go to: https://huggingface.co/
2. Create a FREE account (no credit card needed)
3. Go to: https://huggingface.co/settings/tokens
4. Click "New token"
5. Name it: "T-Shirt Designer"
6. Select role: "read"
7. Click "Generate token"
8. COPY the token (starts with: hf_)

STEP 2: Add Token to Application
---------------------------------
1. Open file: /server/.env
2. Find this line:
   HUGGINGFACE_TOKEN=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
3. Replace with YOUR token:
   HUGGINGFACE_TOKEN=hf_YourActualTokenHere123456789

STEP 3: Start the Application
------------------------------
Terminal 1 (Backend):
   cd server
   python main.py

Terminal 2 (Frontend):
   npm run dev

STEP 4: Open in Browser
------------------------
Go to: http://localhost:3000
Click: "Custom Studio"
Start designing! 🎨
